# Operation-level reference for adapter authors

The base URL and path below identify an official operation or resource family. Braces mark provider-supplied identifiers, never strings for a volunteer to construct. Prefer the official SDK or current versioned schema where appropriate. Restrict grants to selected operations. A remote endpoint being callable does not authorize modifying a congregation's production channel.

## Adapter return values

A playback descriptor supplies mode, public label, safe canonical action, stable media/player identifier, allowed origin, privacy kind, token expiry if applicable, audio/caption tracks, optional alternate and last check. Never add the server credential used to obtain it. A recording descriptor supplies source asset ID, session ID, track kind, export state, expiry, expected length/duration if available, and an internal action to fetch a fresh private transfer ticket.

A calendar projection supplies remote object kind, ID/revision, owner, parent series where applicable, time/zone and whether edit affects one occurrence or the series. Mark fields unsupported individually. A timing API that starts a paid encoder must surface that side effect. The renderer cannot call create/update/remote-delete methods.

## Version drift

Pin the provider API version where supported. Read and store capabilities during authorization. When a field disappears, keep the last good mapping and visible local service, suspend just the affected automation, and show which provider operation needs attention. Do not automatically fall back to scraping embed HTML or deriving a download URL. Functional certification requires a provider read/write/readback cycle for each advertised operation in the selected account class.
