# YouTube Live

Offer two levels. A church can paste a specific existing watch URL or video ID for player/link use. A church that enables calendar automation authorizes its own channel via Google OAuth. Do not require a Google login from the viewer for ordinary public embeds. Some events are private, age restricted, owner-restricted, geo-restricted or blocked by church networks. An alternative provider is a separate source authorized by that church.

## Account and objects

Use a registered Google application, per-installation redirect URI and protected OAuth state. A distributed Joomla component cannot ship a confidential shared client secret. Offer church-managed OAuth client configuration. Disclose any separately operated consent broker if one is ever offered. Bind the resulting token to the intended channel, including selection of the intended Brand Account. Retain offline access securely for unattended scheduling and reauthorize on revoked grants. Use youtube.readonly for observation where sufficient and an accepted scope such as youtube.force-ssl for authenticated writes. Verify actual scopes after consent.

A liveBroadcast represents the audience event and shares the YouTube video ID. A liveStream is the encoder configuration. A reusable liveStream can be bound to different broadcasts at different times. Store the channel ID, event/video ID and stream ID separately. Keep ingestion addresses/keys and monitor embeds private. Preserve an already configured encoder. A watch URL can be used with no API credentials.

| Action | Operation and data |
| --- | --- |
| Import | Page through liveBroadcasts.list using an allowed filter such as mine=true, or broadcastStatus and type per the method's filter rules. Request snippet, status and contentDetails. Adopt by channel/event ID and compare scheduledStartTime, title, privacy and boundStreamId. |
| Create from Joomla | liveBroadcasts.insert with snippet.title, snippet.scheduledStartTime, optional scheduledEndTime, and status.privacyStatus. Preserve audience/child-directed settings as required. Persist returned broadcast ID immediately. |
| Attach existing encoder | liveStreams.list or create only with explicit consent. liveBroadcasts.bind with broadcast ID and streamId. Keep a failed bind as a repairable pending operation. Never create a duplicate broadcast on retry. |
| Reschedule | Use liveBroadcasts.update for fields writable in that lifecycle state. Read current values before updating a part so omitted mutable fields are not lost. Mirror each Joomla occurrence individually. One stable channel link is not a recurring event. |
| Cancel | Preview whether the selected operation removes the remote broadcast. Require explicit ownership and eligible state for destructive removal. Keep a local cancellation notice and audit. An active/completed event or an externally managed event needs an operator decision. |
| Live state | Poll liveBroadcasts.list for bound outgoing events. Use status.lifeCycleStatus and actualStartTime/actualEndTime. Monitor/testing data is private. An encoder accepting input or upcoming status alone does not mark live. Start/stop transitions and auto-start/auto-stop affect production and require explicit settings. |
| Playback | Use the official iframe/IFrame Player API with video ID, origin/referrer and allowed parameters. Check contentDetails.enableEmbed or videos.status.embeddable, then handle iframe errors including 101/150 and 153. A player can still fail per viewer. Offer https://www.youtube.com/watch?v={video_id} or another approved destination. |
| Archive | Store the same video ID as the provider replay after processing if the owner permits. The public Data/Live API does not provide an ordinary video download. No audio extraction, iframe recording or off-platform copy from YouTube playback. Accept the church's encoder file or separately authorized original. |

An unlisted YouTube link is accessible to anyone with that link. Member-only Joomla menus cannot revoke it. Surface this limitation before publishing an access-restricted service. An organization-wide “No YouTube” setting must prevent loading YouTube frames, scripts, thumbnails, preconnect and embeds, including on the Preacher page. A church-approved audio or alternative provider can still play. A link alone does not bypass a network block.

Test re-grant to a different channel. Duplicate schedule submissions. A provider-side edit. A reusable stream bound to two non-overlapping Sundays. Public embed disabled. Viewer blocked from YouTube. A quota error followed by retry. Local upload of original after the YouTube archive is private. Expect one sermon with independent sources.
